## 2. Architecture Analysis

### Electron Main Process (`desktop/main.js`)
- **Lifecycle:** `app.on('ready')` → `startBackend()` → `createWindow()`
- **Backend Spawn:** Spawns `uvicorn backend.main:app` with generated token via `LOCAL_API_TOKEN` env var
- **Security:** Context isolation ✓, Node integration ✗, Sandbox ✓, CSP ✓, IPC allowlist ✓
- **CRITICAL DEFECTS:**
  1. `crypto` module required but `crypto.getRandomValues()` is Web Crypto API (browser only). Node.js crypto uses `randomBytes()` or `randomFillSync()`. → **Startup crash**
  2. `require('electron')` returns executable path string ("Electron...") instead of module on Windows → **app undefined, cannot start**
  3. Token generated by Electron, passed to backend, but backend generates its own token ignoring env var → **Auth mismatch (401)**

### Preload → Renderer (`desktop/preload.js`)
- **Exposes:** `window.api` (campaigns, discovery, backup, health), `window.shell`, `window.app`, `window.electron`
- **CRITICAL DEFECT:** Duplicate `campaigns` property in exposed object literal (lines 50-62 and 71-75). Second overwrites first → `campaigns.list()` and `campaigns.get()` lost, only `campaigns.save()` remains → **Frontend campaign browsing broken**

### FastAPI Backend (`backend/main.py`)
- **Lifespan:** `init_database()` → `run_migrations()` → token handling
- **Auth:** `AuthMiddleware` validates `X-Local-API-Token` header against `token_manager`
- **Routes:** 9 modules under `/api/v1` (health, dashboard, campaigns, sources, discovery, verification_risk, eligibility, category, backup)
- **Static Files:** Mounts frontend at `/` for browser mode

### Database
- **Migrations:** 7 sequential SQL files (001-007)
- **Tables:** campaigns, campaign_evidence, campaign_risk_findings, campaign_eligibility, campaign_field_history, campaign_lifecycle_events, campaign_merge_audit, sources, scan_history, user_tracked, user_notes, settings
- **Connection:** Thread-local pool with WAL mode, FK enforcement
- **Issue:** Migration 002 and 005 both create `risk_rules` table (conflict risk)

### Discovery System
- **Adapters:** CoinGecko, DefiLlama, GitHub, RSS (4 of 7 spec-required)
- **Missing:** Galxe, Layer3, Official sites
- **Orchestration:** `DiscoveryService.run_scan()` with semaphore concurrency limit (3), health checks, partial failure handling
- **Deduplication:** Stable ID (project+name+network hash), fuzzy matching (0.85 threshold), merge audit trail
